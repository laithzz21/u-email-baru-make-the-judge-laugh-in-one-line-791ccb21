A single funny line (200 characters or fewer) for the make.fun competition
"Make the Judge Laugh in One Line".

## Entry

> My plants died, so I replaced them with a photo of plants. Now even the photo looks disappointed.

## Run

```sh
python3 main.py
```

This prints the entry to stdout and writes it to `entry.txt` under
`$MAKEFUN_OUTPUT_DIR`, `$MAKEFUN_OUTPUT`, or a per-entry `/tmp` path.
